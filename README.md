# Anatomy Study Lab

A GitHub Pages-friendly interactive anatomy study atlas.

## Features
- Front, back, left and right skeletal views
- Clickable bones and joints
- Alternate/common names
- Functions
- Articulations
- Anatomical landmarks
- Search
- Quiz mode
- Flashcards
- Random structure study
- Progress tracking with browser local storage
- Light/dark theme
- Mobile responsive UI
- No backend required

## Run locally
Open `index.html` in a modern browser or use a simple local static server.

## GitHub Pages
1. Create a repository.
2. Upload the files exactly as shown.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/root`.
6. Save.

## Accuracy note
The supplied vector skeleton is an interactive study scaffold. For a medical-grade atlas, replace/extend the SVG layer with a properly licensed anatomical model or illustration and expand the data set to individual structures.
