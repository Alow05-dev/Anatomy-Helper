# ANATOMY X — Ultimate Anatomy Study Lab

GitHub Pages-ready, dependency-free anatomy study app.

## Included
- Front / posterior / left / right skeletal views
- Clickable bones and joints
- Jaw / TMJ
- Skull, ribs, vertebral regions, pelvis
- Upper and lower limbs
- Hands and feet
- Finger and toe phalanx groups
- Major carpals and individual scaphoid/lunate entries
- Search by name, alternate name, region and landmarks
- Function, articulations and landmarks
- Rapid-fire quiz
- Flashcards
- Random structure mode
- XP, streaks, daily mission and atlas coverage
- Dark futuristic visual design
- Mobile responsive layout
- No frameworks, packages, APIs or backend required

## Deploy
Upload the contents of this folder to a GitHub repository.
Then GitHub → Settings → Pages → Deploy from branch → main → /root.

## Important
The interactive SVG is an original study illustration, not a medical-grade 3D anatomical scan. For clinical/medical education, verify anatomy against a current anatomy textbook or licensed atlas.
