# Anatomy X — 3D Human Anatomy Lab

Upload `index.html` to a GitHub Pages repository.

This build uses Three.js and loads open anatomical 3D meshes from the BodyExplorer project through jsDelivr:
- 201-bone skeleton mesh
- 467 muscle/tendon/connective-tissue meshes
- click-to-identify
- search
- front/back/left/right
- pinch/drag/zoom
- bone-only / muscle-only / X-ray
- opacity controls
- explode view
- quiz mode
