# Anatomy X — 3D Human Anatomy Lab

This build uses Three.js and the browser-ready `body.glb` from:
https://github.com/hpfrei/body-anatomy-3d-viewer

The upstream project documents the model as a 6.9 MB DRACO-compressed Z-Anatomy model with embedded anatomical metadata for muscles and bones. It is designed to work in Safari and other modern browsers.

Features in this app:
- real 3D anatomy
- 360° orbit controls
- mobile pinch/zoom/pan
- clickable anatomical structures
- search
- front/back/left/right views
- bone-only / muscle-only
- X-ray
- opacity controls
- exploded view
- quiz mode
